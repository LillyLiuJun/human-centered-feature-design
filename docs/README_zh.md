<div align="center">
  <h3>以人为中心的产品功能设计</h3>
</div>


> *“人不是产品的变量，产品才是人的变量。需求来自偏离平衡，产品无法凭空制造渴望，只能成为恢复稳态的出口。”*

**以人为中心的功能设计 (Human-Centered Feature Design)** 是一套**让功能重归人的平衡，而非制造虚假动机**的情境推理框架。它从宏观功能契约深入到微观交互边界，严密推导用户在具体处境下的真实心理机制，检验并打磨方案——确保功能真正契合现实需求，坚决剔除团队自嗨与虚假粘性。

---

### 常见触发场景（提示词示例）

你可以在以下场景中直接调用本 Skill：

* **界定核心契约（展示什么促成使用）**：*“帮我看看这个卡片应该展示哪些数据和信息，才能真正契合当下情境，促使用户去使用？”* ➔ [案例 01：话题卡重构](#案例-01话题卡重构内容契约与处境的对齐)
* **推导微观交互的情境边界**：*“帮我看看用户的真实需求以及该如何设计交互：比如卡片展开在切走或失焦时的边界，何时保留状态、何时静默复位？”* ➔ [案例 02：动态阅读状态](#案例-02动态阅读状态三重处境边界的拆解)
* **现有功能去伪存真**：*“用本框架的三大黄金法则审查当前方案，剔除团队自嗨与虚假动机。”*

## 真实业务实战复盘 (Production Retrospectives)

本框架附带了两篇真实商业产品（AI 语言沉浸应用）的设计复盘，完整展示了情境推理如何解决实际的烂摊子：

### 案例 01：话题卡重构——内容契约与处境的对齐
> 完整复盘文档：[`examples/01-talk-about-today-cards.md`](../examples/01-talk-about-today-cards.md)

* **起因与伪设计**：团队原本以为“今日话题”卡片点击率低是卡片太丑、配图不够吸引人，准备做更多视觉动效和海量分类推荐。
* **情境心理诊断**：
  1. 用户在“固定练习时段”打开 App，其动机已经非常充沛，无需被额外刺激；
  2. 真正的阻碍是**决策阻力**——面对海量类目（电影、科技、旅游），用户不知道“点进去要聊多久、要聊什么、能不能聊完”；
  3. 卡片入口承诺“聊聊昨天的梦”，点击进去交付的却是一个宽泛的分类列表，造成了严重的**契约断裂**。
* **重构落地**：从“分类类目”重构成“明确契约卡”；将静态库存逻辑改为“消化欠账”逻辑；入口承诺精确对齐交付，决策摩擦直接归零。

---

### 案例 02：动态阅读状态——三重处境边界的拆解
> 完整复盘文档：[`examples/02-expand-collapse-state.md`](../examples/02-expand-collapse-state.md)

* **起因与伪设计**：为了让用户“完整沉浸阅读”，团队做了卡片点击全量展开，但发现状态一旦持久保留，用户再次回到主屏时面对一堆展开的长卡片极度烦躁；而若机械定时收起，又会切断用户的阅读心流。
* **情境心理诊断**：
  1. 展开卡片不是内容的固有持久状态，而是用户在特定视口下的**“临时注意力焦点”**；
  2. 当用户的注意力转移（滑出屏幕、切换 Tab、锁屏离开），这一临时注意力状态已自然消亡；继续保留展开不仅不是贴心，反而制造了界面杂乱与认知欠账。
* **重构落地**：推导出严密的三重处境边界：
  * *视口内微中断*（接电话、短暂停顿）➔ **坚决保护心流，不收起**；
  * *完全离开视口*（滑出屏幕范围）➔ **静默平滑复位，无视觉突变**；
  * *离开当前模块*（切换 Tab 或退出页面）➔ **隐形重置，恢复初始秩序**。

## 底层哲学 (Philosophy)

本框架的一切情境推演建立在一个根本认知之上：**产品是帮人重归平衡的工具，而非收割人类注意力的机器。**

```
处境中的人（产生失衡） ──► 产品作为隐形泄压阀 ──► 重归生理与心理稳态 · 沉淀真实掌控感
```

这一底层哲学在工程实践中具体拆解为三大支柱：

1. **系统稳态高于虚假动机 (Homeostasis)**：需求源于人生理与心理偏离平衡的张力。产品无法凭空制造渴望，只能成为离散任务或连续心流的顺畅出口（管理“消化欠账”，而非堆砌“静态库存”）。
2. **主观能动高于系统操纵 (Agency)**：人认知脆弱但渴望掌控。系统在感知、搜索、决策、行为、评价与习惯六大触点上提供隐形支架，并把所有成就归功于用户。**好的系统永远是安静的。**
3. **处境感知高于机械触发 (Context)**：产品的影响力是借来的，完全取决于与真实空间、生理节律与认知余量的匹配度。通过行为设计模型精准诊断能力与时机缺口，杜绝无差别的机械红点与弹窗轰炸。

### 三条黄金检验原则 (The Three Litmus Tests)
在敲定任何功能原型或交互细节前，用这三个问题终审自检：
* **这个设计是在帮用户回到平衡，还是在制造新的焦虑？**
* **这个设计让用户感觉是自己在掌控，还是被系统机制牵着走？**
* **这个设计无感嵌入了用户的真实处境，还是在制造脱离处境的噪音？**
